# Reference Scout coding-quality A/B benchmark

This benchmark compares two fresh copies of the same small TypeScript project:

- `baseline/`: generated by DSH without Reference Scout.
- `with-plugin/`: generated by the same DSH model with Reference Scout enabled.

Both runs receive the exact task in `task.txt`. Quality is checked afterward with
`hidden/async-ttl-cache.hidden.spec.ts`; the hidden tests are not present in either
candidate workspace while the model is coding. A run is stopped only after the
public tests and typecheck pass against an unchanged source hash for four probes
(about 32 seconds), with a four-minute hard ceiling. `results.md` records the
measured test score, type-check result, elapsed time, and DSH token projection.

The benchmark is a single paired run, so it is evidence about this task—not a
general statistical claim about coding quality.

The runner expects two DSH profiles: `rs-bench-base` with the base/headless bundles,
and `rs-bench-scout` with those bundles plus a link to this package. Run both variants
with `node scripts/run-quality-benchmark.mjs`, or append `baseline` / `with-plugin`
to replace only one result in `results.json`.
